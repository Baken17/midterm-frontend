About the role

Acme Corp builds accessible tools that help teams work together. We are looking for an early-career Frontend Developer to turn designs into clear, responsive interfaces.

You will work with designers and developers, receive feedback through code reviews, and gradually take ownership of small features.

Responsibilities

  • Build responsive pages and reusable UI components.
  • Translate design mockups into accessible HTML and CSS.
  • Use JavaScript and React to add interactive features.
  • Test layouts across browsers and screen sizes.
  • Collaborate with the team and participate in code reviews.

Requirements

  • Good knowledge of HTML, CSS and responsive design.
  • Basic JavaScript and React experience.
  • Familiarity with Git and GitHub.
  • Clear communication and willingness to learn.
  • A small portfolio of projects; coursework is welcome.
